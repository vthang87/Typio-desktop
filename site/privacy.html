Typio Desktop Privacy Policy

Last updated: November 9, 2026

Typio Desktop is an app for macOS and Windows that shows typing suggestions and expands shortcuts from your own datasets in the apps you use. This policy explains what it does with your data.

Summary

Typio Desktop does not collect, transmit, sell or share any personal data. Everything stays on your computer.

Data stored on your computer

Typio Desktop saves the following in its data folder on your computer only (Settings → Open Data Folder shows where):

  • Datasets and shortcuts: the suggestion lists and shortcut tables you create or import.
  • Settings: your trigger character, language, which datasets are on, and which apps Typio skips or runs in.

What Typio reads while you type

To show suggestions, Typio watches the keys you press and reads the text near the cursor in the focused field. It uses this only in memory, at that moment, to find matches. It does not record, log or store what you type. It never reads password fields, and it does not run in apps you skip.

On macOS this needs the Accessibility permission, which you grant in System Settings and can revoke there at any time.

Data Typio never sends

Typio Desktop has no account, no backend server, no analytics, no advertising and no cloud sync. It makes no network requests with your data. Your datasets, shortcuts, settings and anything you type are never sent to the developer or to any third party.

Your control

  • Export a backup of your data as a JSON file, saved only where you choose.
  • Edit or delete any dataset from Settings.
  • Turn Typio off, or skip any app, from the menu.

To remove everything, quit Typio, delete the app and delete its data folder.

This website

This website is hosted on GitHub Pages and the app downloads are served by GitHub Releases. The site sets no cookies and runs no analytics. It asks the GitHub API for the latest version number. Like any website, GitHub processes standard request data such as IP addresses to deliver the pages and files.
